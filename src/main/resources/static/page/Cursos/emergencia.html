React Right
Todos niveles

Descripción

El programa React Right de SSI es un curso de primeros auxilios diseñado específicamente para buceadores y cualquier persona interesada en aprender a reaccionar ante emergencias.

Incluye formación en RCP, uso de oxígeno y evaluación neurológica básica para responder correctamente en situaciones críticas.

Contenido del curso

  • Reanimación Cardiopulmonar (RCP)
  • Uso de Desfibrilador Externo Automático (DEA)
  • Primeros auxilios básicos
  • Administración de oxígeno
  • Evaluación neurológica

Requisitos previos

  • Ser mayor de 12 años
  • No se requiere certificación previa

Información adicional

  • Duración: 8-10 horas
  • Nivel: Todos
  • Certificación internacional SSI
